# use cases

intended user is a developer using coding agent.  can be the developer's manager as well.  this will breakdown all activity in a user friendly way and provide any threat analysis.

* a quick dashboard to note any irregularities or things that need attention
* user should be alerted of any potential harmful actions for review
* show the timeline of actions, the changes that those caused, should be high level at first, some description, then drill into the specifics eg. agent read this file at /tmp/xyz.txt then changed this value here, at this time.  should correlate prompt to actions taken.
* what files were modified, read, executed


## dashboard

* any potential threats or irregularities
* agent sessions info, how many, activity, commands executed, files touched, etc
* file access summary (crud + executed)
* network access like a web search

should delineate from a session perspective as well, the above is general/all sessions.
