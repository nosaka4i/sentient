sentientd options

sentientd is the Sentient monitor. It runs as root under systemd, reads kernel events and agent session logs, and serves the local API that sen uses.

Flags

Set flags on the ExecStart line of /etc/systemd/system/sentientd.service, then run sudo systemctl daemon-reload and sudo systemctl restart sentientd.

FlagDefaultDescription
--data-dir/opt/sentient/dataDirectory holding sentient.db.
--socket/run/sentient/sentientd.sockUnix socket for the local API.
--socket-groupsentientGroup allowed to connect to the socket. Empty means owner only.
--home/root, /home/*Home directory whose ~/.claude/projects to read. Repeatable.
--poll-interval2sHow often session logs are checked for new records.
--integrity-interval1hHow often the full hash-chain check runs.

Examples

Watch one account only

ExecStart=/opt/sentient/bin/sentientd --home /home/agent

Watch two accounts

ExecStart=/opt/sentient/bin/sentientd --home /home/agent --home /home/ci

Files

PathDescription
/opt/sentient/bin/sentientd and sen binaries.
/opt/sentient/data/sentient.dbThe record. SQLite, root-only, hash-chained.
/run/sentient/sentientd.sockThe local API socket.
/etc/systemd/system/sentientd.serviceThe systemd unit.
