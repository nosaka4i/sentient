sen CLI reference

sen is the Sentient command line tool. It runs as you and asks sentientd what your coding agent did. It never touches your projects.

Commands

CommandWhat it does
sen statusWhat needs your attention, then the last 24 hours of activity and recent prompts.
sen serveServes the web dashboard on localhost.
sen versionPrints the version.
sen alert <#> PlannedDetails for one attention item.
sen session <id> PlannedThe prompts in one session.

sen status

Alerts first, then a summary of activity in the window, then the window's prompts. It reads what sentientd has stored, current to the second.

$ sen status
Monitored from Oct 6 09:12 (1d 6h ago)

NEEDS ATTENTION (4)
#    DATE          AGENT    REPO     SEVERITY   RESOURCE   ACTION    PATH
43   Oct 7 14:52   claude   nosaka   high       file       update    ~/.zshrc
41   Oct 7 14:33   claude   nosaka   medium     file       update    ios/Config.plist
...

LAST 24H
RESOURCE    ACTION    COUNT   SUMMARY
file        read      214     38 outside repo
file        update    9       +248 −61
command     execute   41      2 failed
network     connect   5       github.com, registry.npmjs.org, localhost:3000

Columns are separated by tabs. When piped, the output is raw tab-separated text, so cut and awk work on it.

Flags

FlagDefaultDescription
--socket$SENTIENT_SOCKET or /run/sentient/sentientd.sockThe sentientd socket.

sen serve

Serves the web dashboard. It listens on loopback only.

sen serve                       # http://127.0.0.1:7357
sen serve --addr 127.0.0.1:8080

Flags

FlagDefaultDescription
--addr127.0.0.1:7357Loopback address to listen on.
--socket$SENTIENT_SOCKET or /run/sentient/sentientd.sockThe sentientd socket.

From another machine

Use an SSH tunnel, then open http://127.0.0.1:7357 locally. Tailscale works too.

ssh -N -L 7357:127.0.0.1:7357 <host>

sen version

Prints the sen version.

$ sen version
sen 0.1.0

Environment

VariableDescription
SENTIENT_SOCKETPath to the sentientd socket. --socket takes precedence.
