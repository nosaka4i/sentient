API reference

sentientd serves a local gRPC API over its Unix socket. sen and the dashboard are its clients, and you can build your own.

The API is read-only and has no network port. The definition is sentient.proto, package sentient.v1, service Sentient.

Placeholder. The API is still changing and isn't stable. Field-level docs will be generated from sentient.proto when it settles.

Connecting

Connect to unix:///run/sentient/sentientd.sock. Your account must be in the sentient group.

grpcurl -plaintext -unix /run/sentient/sentientd.sock \
  -import-path internal/api/sentientpb -proto sentient.proto \
  sentient.v1.Sentient/Health

Methods

Status(StatusRequest) → StatusResponse

The data behind sen status and the dashboard home.

Health(HealthRequest) → HealthResponse

Sentient's own state, shown on /health.

ListPrompts(ListPromptsRequest) → ListPromptsResponse

Prompts, newest first.
